# IDICACIONES para trabajar en el proyecto

## Limites al usar GIT
    - No debes hacer comandos de git tu solo, siempre que lo necesites pideme permiso. Usualmente no será necesario ya que yo los haré.

    - A la hora de estar trabajando siempre has cambios en local, haz una prueba o test de tus cambios y si funcionan, dame un resumen de lo que hiciste y si funciona o no.
